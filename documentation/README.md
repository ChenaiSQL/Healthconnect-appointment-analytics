# HealthConnect Appointment Analytics

## Project overview

This Week 5 project analyses appointment attendance and no-show patterns for HealthConnect using Microsoft Power BI. The dashboard establishes a descriptive baseline and identifies factors associated with appointment non-attendance.

## Project objectives

- Measure appointment attendance and no-show performance.
- Monitor monthly changes in the no-show rate.
- Compare no-show rates across appointment types and times.
- Examine previous no-show history, booking lead time and reminder status.
- Recommend operational actions that could improve attendance and appointment-capacity use.

## Tools used

- Microsoft Power BI Desktop
- Power Query
- DAX
- Microsoft Excel and CSV data

## Key performance indicators

- Total appointments: 5,000
- No-show appointments: approximately 2,400
- No-show rate: 51.2%
- Cancellation rate: 5.3%
- Reminder coverage rate: 72.7%
- Repeat no-show rate: 57.8%

## Dashboard pages

### Overview

The Overview page presents the principal KPIs, the monthly no-show trend, average booking lead time by outcome and no-show rates by appointment type.

### Attendance Drivers

The Attendance Drivers page examines no-show rates by appointment time, previous no-show history and reminder status.

Both pages include Year-Month and Appointment Type slicers for interactive filtering.

## Key findings

- Patients with previous no-shows had a higher no-show rate than patients without previous no-shows.
- Follow-up appointments recorded the highest no-show rate among the appointment categories.
- No-show appointments had the longest average booking lead time.
- Appointments without a recorded reminder had a higher no-show rate.
- Monthly no-show rates fluctuated over the reporting period, supporting continued monitoring.

## Recommendations

- Prioritise confirmation and rescheduling support for patients with previous no-shows.
- Improve reminder coverage and capture reminder-delivery information.
- Use staged reminders for appointments booked well in advance.
- Pilot interventions for follow-up appointments.
- Monitor monthly results using consistent KPI definitions.

## Limitations

The analysis is descriptive and does not establish causation. It uses one supplied dataset, and some operational factors—including staffing, capacity, transport barriers and reasons for non-attendance—were unavailable.
