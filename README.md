# Healthconnect-appointment-analytics
PowerBI analysis of appointment attendance and no-show patterns for the HealthConnect Week 5 project




## Week 7 – Analytical Testing, Refinement & Validation

Week 7 focused on testing the accuracy, consistency and usability of the HealthConnect Power BI dashboard.

### Completed activities
- Validated key KPI values
- Tested the Year-Month slicer using April
- Tested the Appointment Type slicer using General Consultation
- Added a Validated Key Findings section to the dashboard
- Re-tested the dashboard after refinement
- Documented testing evidence and limitations

### Validated KPIs
- No-show rate: 51.2%
- Cancellation rate: 5.3%
- Reminder coverage: 72.7%
- Repeat no-show rate: 57.8%

### Limitation
Week 6 cross-track integration was not completed, so Data Science validation remains an outstanding dependency for Week 8.

See the `Week7` folder for the report, project summary, testing record and screenshots.


## Week 8 - Final Integration, Presentation & Project Showcase

Week 8 focused on finalising the HealthConnect Data Analytics contribution and preparing it for the final project showcase.

### Final activities
- Confirmed the final KPI values
- Finalised the Power BI dashboard
- Reviewed validated no-show and attendance findings
- Developed final business insights and recommendations
- Prepared the final analytics report
- Prepared presentation materials and video presentation content
- Documented remaining analytical limitations and integration requirements

### Final validated KPIs
- No-show rate: 51.2%
- Cancellation rate: 5.3%
- Reminder coverage: 72.7%
- Repeat no-show rate: 57.8%

### Key recommendations
- Prioritise patients with previous no-show history for additional follow-up
- Improve reminder coverage
- Monitor longer booking lead times
- Use appointment-type segmentation to identify higher-risk areas
- Continue using the dashboard for attendance monitoring and decision support

### Final status
The analytics dashboard, report and presentation materials are ready for final submission and showcase.

See the `Week8` folder for the final project files.
